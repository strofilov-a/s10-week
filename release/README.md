# «Моя неделя» и страница S10 Solo · релиз 70ad4cb97c

## Как обновить

Заменить на сервере файлы из архива, на те же места, что в прошлый раз:

| Файл в архиве | Адрес на сайте | В этом релизе |
|---|---|---|
| `t5/solo/solo.js` | `/t5/solo/solo.js` | **изменился** |
| `solo.html` | `/solo/plan` | **изменился** |
| `solo-start.html` | `/solo/start` | **изменился** |

Можно не разбираться и заменить все три файла: те, что не менялись, в архиве такие же байт в байт, как на сервере. Больше ничего не нужно: ни сборки, ни правок в коде сайта. Когда замените, напишите нам, сайт мы проверим сами.

**Один раз, если ещё не сделано:** отдавать `/solo/plan` и `/solo/start` с заголовком `Cache-Control: no-cache`. Сейчас у этих адресов `Cache-Control` нет, и после обновления браузер может ещё несколько дней показывать старую страницу. С `no-cache` браузер при каждом открытии спрашивает сервер, не изменился ли файл (по ETag), и новую версию получает сразу. `/t5/solo/solo.js` можно оставить как есть: его адрес в `solo.html` меняется с каждой версией (`?v=`).

## Первая установка (сделано 6 ноября 2026)

Это уже сделано, повторять не нужно. Оставлено для справки.

- **«Моя неделя»** (`/solo/plan`) — сама страница Solo для залогиненного спортсмена.
- **Страница S10 Solo** (`/solo/start`) — рекламная страница для людей из Instagram и Threads. Все её кнопки ведут на вход в S10 с возвратом на `/solo/plan`.

1. Положить `t5/solo/solo.js` на сервер как `/t5/solo/solo.js`.
2. Добавить маршрут `/solo/plan`, который отдаёт `solo.html` так же, как сейчас отдаётся `/calc3`. Все адреса `/solo/…` уходят в страницу клуба S10 Solo, поэтому маршрут нужно поставить раньше клубного. Сама страница клуба `/solo` не меняется.
3. Добавить маршрут `/solo/start`, который отдаёт `solo-start.html` как есть, тоже раньше клубного. Страница открывается без входа (на неё придут люди без аккаунта), запросов к сайту не делает, cookie не нужны.
4. Добавить в меню спортсмена пункт «Моя неделя» со ссылкой на `/solo/plan`.

Сборки нет. `solo.js` — один JS-файл без зависимостей. `solo-start.html` — один HTML-файл, всё внутри (стили, скрипты анимации GSAP и Lenis), снаружи только шрифты Google Fonts. Бэкенд, база и страницы calc3/calc4/calc5 не меняются. «Моя неделя» работает через существующие запросы сайта (`/apiweb/…`, `/student`, генератор планов calc4) с cookie сессии, как calc3.

### Проверка

1. Открыть `https://s10.run/solo/plan` под своим аккаунтом: видна текущая неделя с тренировками. Новый пользователь без главного старта сначала увидит окно «Главный старт».
2. Открыть `https://s10.run/solo/start` в окне без входа (инкогнито), на компьютере и на телефоне. При прокрутке большой красный круг с цифрой 6 уменьшается и садится на 6 декабря в календаре, календарь заполняется, блоки «Сначала вы пишете цель» и «Что умеет Solo» листаются по шагам.
3. Нажать «Попробовать Solo»: откроется вход в S10, после входа — `/solo/plan`.
