# «Моя неделя»: встроить в s10.run

Страница готова и проверена на живом сайте. Нужно только встроить её; логику, тексты и правки дальше делаем мы.

## Что в папке

| Файл | Куда |
|---|---|
| `t5/solo/solo.js` | на сервер как `/t5/solo/solo.js` |
| `solo.html` | отдавать по адресу `/solo/plan` |
| `README.md` | эта инструкция |

## Что сделать

1. Положить `t5/solo/solo.js` на сервер как `/t5/solo/solo.js`.
2. Добавить маршрут `/solo/plan`, который отдаёт `solo.html` так же, как сейчас отдаётся `/calc3`. Сейчас все адреса `/solo/…` уходят в страницу клуба S10 Solo и `https://s10.run/solo/plan` отвечает 500, поэтому маршрут нужно поставить раньше клубного. Сама страница клуба `/solo` не меняется.
3. Добавить в меню спортсмена пункт «Моя неделя» со ссылкой на `/solo/plan`.

Больше ничего не нужно. Сборки нет: это один JS-файл без зависимостей. Бэкенд, база и страницы calc3/calc4/calc5 не меняются. Страница работает через существующие запросы сайта (`/apiweb/…`, `/student`, генератор планов calc4) с cookie сессии, как calc3.

## Когда мы пришлём новую версию

Придёт такая же папка. Заменить `/t5/solo/solo.js` и `solo.html`: в `solo.html` уже стоит новая метка `?v=`, по ней браузеры возьмут новый файл, а не старый из кэша.

## Проверка

Открыть `https://s10.run/solo/plan` под своим аккаунтом: видна текущая неделя с тренировками. Новый пользователь без главного старта сначала увидит окно «Главный старт».
