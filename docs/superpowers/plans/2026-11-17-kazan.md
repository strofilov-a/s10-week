# S10 Solo · Казань — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** страница `/solo/kazan`: «Моя неделя» в режиме Казанского марафона 2 мая 2027, цель 3:00, 3:30 или 4:00, один план владельца, от цели зависят темпа и километраж.

**Architecture:** режим внутри `solo.js` (подход 1 из дизайна). По адресу `/solo/kazan` (в демо `?kazan`) переменная `MODE = 'kazan'` подменяет выбор плана выбором цели. План владельца встроен константой и разбирается новым разборщиком формата экспорта calc4. Старт зафиксирован, объём и длительные масштабируются от цели. Всё остальное — общий код Solo. Для программиста режим прокидывается в `engine.ts` опцией `mode`, рядом лежит новый корневой компонент `SoloKazan.tsx`.

**Tech Stack:** plain JS в одном файле `solo.js` без сборки. Тесты — Node + Playwright (`tests/*.cjs`). Для программиста — генератор `deploy/react-src.cjs`, React 17 и TS 4.9.

**Spec:** `docs/superpowers/specs/2026-11-17-kazan-design.md`

### Task 3: Объём по цели, длительные и неделя старта

**Files:**
- Modify: `solo.js` — `layWeek` (~строка 411), новая `scaleLongDesc`.
- Test: `tests/kazan.cjs`.

**Interfaces:**
- Consumes: `kazanPlan()`, `KAZAN.scale`, `kazanGoal`.
- Produces: `scaleLongDesc(desc: string, totalKm: number, f: number) → { desc: string, km: number }`. `km = Math.round(totalKm * f)`. Первое «N км», равное `totalKm`, становится новой длиной. Каждое следующее «N км» умножается на `f` и округляется до целого, но не меньше 1. Расхождение суммы частей с новой длиной уходит в последнюю часть. Сумма частей считается так: «K по N км» даёт K×N, «через M км» сразу после него — (K−1)×M, любое другое «N км» — N. Без «N км» в тексте или при `totalKm === 0` описание не меняется. Экспортируется в `S10_TEST`.
- В режиме Казани `layWeek`: коэффициент цели `k = KAZAN.scale[kazanGoal] × soft(w)` (Task 4) умножает цель недели и длительную (`type === 'длительная'`, через `scaleLongDesc`). Остальные слоты не меняются. В неделе старта (−1) лёгкий бег не кладётся: цель недели = сумма слотов. В режиме Solo `layWeek` не меняется.

- [ ] **Step 1: Write the failing tests:**
  - `scaleLongDesc: «26 км. Первые 20 км по T42+45, последние 6 км по T42», 26, 0.7 → «18 км. Первые 14 км по T42+45, последние 4 км по T42», 18`;
  - `scaleLongDesc: 0.85 → 22 км, parts 17 + 5`;
  - `scaleLongDesc: «28 км. Первые 10 км по T42+45, потом 3 по 4 км по T42 через 1 км трусцой, последние 4 км трусцой», 28, 0.7` → длина 20, части в сумме дают 20 (количество повторов «3 по» не трогается, км в «по 4 км» и «1 км» масштабируются) (Review Focus 3);
